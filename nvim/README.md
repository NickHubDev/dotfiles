# KNIGHT-VIM

## 🤔 | What is this?

KNIGHT-VIM is a **special custom config for neovim** based on
[LazyVim](https://github.com/LazyVim/LazyVim) for the base.

## 🫆 | Special Aspects

This config have different special aspects for a nvim
config that are:

- Dark Interface
- Some Plugins pre-instaled for made the User Experecience more comfortable

## 📦 | Dependencies

The only two dependencies for use this project are:

1. Have NeoVim installed
2. Have a computer 😉
